# Book Reading List Application

A browser app to keep track of the books you want to read, are reading, or have finished.

## Features
- Add a book with title, author and status
- Change a book's status at any time
- Filter by All, To read, Reading or Finished
- Delete books
- Summary counts for each status
- Saves your list in the browser, so it is still there after a refresh
- Responsive layout with dark mode support

## Technologies
HTML, CSS, JavaScript (DOM manipulation, localStorage)

## How to run
Open `index.html` in any browser.
